# Plan Tracker — 플랜 동기화 스킬

이 스킬은 PLAN.md를 갱신하는 **유일한** 안전 경로다. 직접 Edit로 PLAN.md를 만지지 말 것.

## 트리거

- verifier가 5단 게이트 통과 + 작업 ID(예: `1.7`)를 알 때
- 사용자가 `/checkpoint` 명령 실행
- 사용자가 "지금 어디까지 했어?" / "다음은?" 류 질문

## 단계

1. **현재 상태 읽기**: PLAN.md 파싱 → 항목 배열
2. **갱신**:
   - 입력으로 `(itemId, newStatus)` 받음 — `[x]`로 마킹
   - 합계 표 자동 재계산 (페이즈별 + 전체)
   - "최종 업데이트" 컬럼에 ISO 날짜
3. **다음 항목 추천**: 
   - 같은 페이즈에서 의존성 없는 다음 `[ ]` 한 개 추출
   - 페이즈 끝났으면 다음 페이즈 첫 항목
4. **출력**: 변경된 라인 diff + 다음 작업 한 줄

## 안전 룰

- `[x]` → `[ ]`로 되돌리는 작업은 **사용자 명시 확인** 필수
- 항목을 지우는 건 architect만 가능
- 합계 표 숫자는 **무조건 자동 계산** (수동 입력 금지)

## 출력 예시

```
✅ PLAN 1.7 완료 마킹

diff:
- [ ] **1.7** Fetcher 인터페이스 정의 (`src/fetchers/types.ts`)
+ [x] **1.7** Fetcher 인터페이스 정의 (`src/fetchers/types.ts`)

페이즈 1 합계: 1/13 → 2/13 (15%)
전체 합계:    1/58 → 2/58 (3%)

▶️ 다음: 1.8 Fetcher 3개 실 구현 (에너지, BE) — Engie BE / Luminus / TotalEnergies BE
```
