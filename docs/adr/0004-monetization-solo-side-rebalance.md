# ADR-0004: MONETIZATION.md 솔로 사이드 재조정 — €0 인건비, €300 인프라 cap, 보수적 매출 가정

## Status

Accepted (2026-05-09) — 본 ADR은 **MONETIZATION.md 본문 자체를 갱신**하는 결정.
산출물: 인건비/마케팅/법무 €0 가정, 인프라 €300/월 cap (격상 트리거 명시),
매출 가정 50% 다운 + 페이즈 일정 동기화, Vlaio/LU 그랜트 시나리오 신설, 시드

## Context

### 운영자 사실 (`docs/FOUNDER.md`)

| 항목 | 사실 |
|---|---|
| 운영자 | Kim Wonmin (베네룩스 거주, TVA 대기 중) |
| 시간 투입 | 솔로, 사이드 (주 10-20시간) |
| 월 운영 예산 | **€300 ALL-IN** (Claude + 도메인 + 인프라 전부) |
| 비즈니스 인프라 | 개인 사업자 ✅, TVA ⏳, 비즈니스 계좌 미개설 |

### 기존 MONETIZATION.md의 비현실성

기존 비용 시뮬레이션:

```
M3      | €15K cost  → 인건비 €55K (4명 풀타임 + 2 파트) 분기 가정
M6      | €45K cost  → 손익분기 (월 €60K 매출 가정)
M12     | €90K cost  → MRR €180K
```

운영자 실제 예산은 €300/월. 즉 **기존 비용 가정의 1/150 수준**. 이 격차는
단순 보정이 아니라 **수익 모델 자체의 가정을 다시 짜야** 한다:

1. **인건비 €0** (운영자 본인 시간 = 사이드 전제로 비용 0). 풀타임 가정 시
   인건비가 매월 가장 큰 비용 → 이 항목 제로화는 cost shape를 근본 변경.
2. **마케팅 €0** (organic only). 페이드 마케팅 €18K/월 가정은 즉시 제거.
3. **법무 €0** (legal 에이전트 100% 의존). FOUNDER.md §2 함의에서 명시:
   "외부 변호사 €800/주는 불가".
4. **인프라 cap €300** — 무료 티어 의존, 매출 발생 후 격상.

### 외부 그랜트 사실 (TVA 발급 후 적격성 확인 필요)

| 그랜트 | 출처 | 자영업자 적격 | 추정 금액 |
|---|---|---|---|
| **Vlaio KMO Portefeuille** (BE Flanders) | [vlaio.be](https://www.vlaio.be/) | ✅ (BE 사업자 + Flanders 거주) | €5K~€20K |
| **Luxinnovation Fit 4 Digital** (LU) | [luxinnovation.lu](https://www.luxinnovation.lu/) | ✅ (LU 사업자) | €15K~€50K |
| **innoviris** (Brussels) | [innoviris.brussels](https://innoviris.brussels/) | 조건 검토 | varies |

운영자 거주가 BE 또는 LU로 추정(FOUNDER.md §1) → TVA 발급 직후 적격성 확인이
실행 가치가 큼. 추정이라 명시 — 실제 거주 지역 확인 후 실 적격성 재평가 필요.

### 매출 가정 보수화 근거

**사용자 명시 가이드라인**: "전환율, 비교 수, 단가 모두 50%로 다운".

- 비교 수 50% 다운 근거: 페이드 마케팅 €18K → €0 → organic만 → 트래픽 획득
  속도가 느림. SEO 진입은 6-12개월의 ramp-up.
- 전환율 50% 다운 근거: 솔로 사이트의 신뢰 확보 시간이 더 걸림. 원 8-12% →
  4-6%.
- 단가 동일 유지: 어필리에이트 단가는 시장 결정이라 운영자 규모와 무관.
- 평균 단가 €25~€70 (통신 BE) → 단일 카테고리에서 보수적.

### PLAN 동기화

ADR-0003의 결정 1 (통신 BE 우선) + 결정 2 (페이즈 5 6개월 평가 게이트) +
결정 4 (페이즈 4 = 베타 + 런치 통합) 를 본 ADR이 비용/매출 가정에 반영.

## Decision

### 결정 1 — 인건비 **€0** 가정 유지 (사이드 전제)

운영자 본인 시간 = 비용 0. 사이드 프로젝트라 본업 수입이 별도. 시간 기회비용
은 *명시적으로 무시* — 사이드의 정의가 그것.

**부수 효과**:
- 손익분기가 매출이 인프라 cap (€300~€500/월)을 능가하는 시점 → **M8 베타
  단계에서 net positive 진입 가능** (원 가정 M6 손익분기보다 더 빠름!)
- 단, "회사 가치"는 인건비를 추정 보정해야 함 (시드 평가 시 운영자 시간을
  €40~€60K/년으로 가산, M24 평가 시점 ADR-XXXX로).

### 결정 2 — 인프라 **€300/월 cap** (M1~M16) + 격상 트리거 명시

무료 티어 우선:
- Vercel Hobby, Neon Free, Upstash Free, Sentry Free, Inngest Free, GitHub Free,
  PostHog Free
- 도메인 €30/년 (등록 완료, 약 €3/월)
- Claude Code 사용료 €80~€150/월 (가장 큰 비용 항목)

**격상 트리거** (운영자 명시 승인 후):
- M10: 매출 ≥ €1,000/월 + 사용자 체감 지연 1건 이상 → Vercel Pro €20 + Neon
  Launch €19 (총 €40 격상)
- M16: 매출 ≥ €3,000/월 + bandwidth ≥ 80GB/월 → cap €500/월 격상 검토
- M24: 시드/풀타임 평가 시 cap 자체 재정의

격상은 **architect 단독 결정 안 함** — 운영자 승인 게이트.

### 결정 3 — 법무 **자체 + 베타 직전 1회 외부 감사** (€800)

- legal 에이전트가 (a) GDPR 처리 등록부 (b) 어필리에이트 디스클로저 (c) 약관
  / 개인정보 처리방침 / 쿠키 정책 작성을 담당.
- 외부 GDPR 감사는 **수익 발생 ≥ €5,000/월 시점**에 시행 — 베타 직전이 아닌
  운영 안정 후. 베타는 100명 한정이라 대규모 GDPR 위반 노출 작음.
- 외부 변호사 €800/주는 **금지** (FOUNDER.md §2 함의 + 본 문서 §4의 솔로
  추가 금지 6, 7).

### 결정 4 — 매출 가정 **50% 다운** + 페이즈 일정 동기화

기존 가정 (페이즈 4 월 €4K, 페이즈 5 월 €44K, 페이즈 6 월 €180K) 대비:
- M8 (베타) €320, M10 (런치) €1,125, M12 €1,800, M16 €3,750
- M18 €7,500, M24 €15,400

전환율 50% 다운, 비교 수 50% 다운, 단가 시장가 유지. 페이즈 일정은
ADR-0003 동기.

### 결정 5 — Slim Plus 시작 시점 **페이즈 6 → M18+** 이연

이유: 솔로에서 무료 사용자 베이스 확보 전 구독 도입 시 (a) 가치 인식 시간
부족 (b) Stripe 운영 부담 (c) 헌법 P3 정신("Plus 강제 금지"). 활성 사용자
≥ 5,000명 신호 후 시작.

### 결정 6 — 시드 모금 **M24+ 평가 시점으로 이연**, Vlaio/LU 그랜트 **TVA 직후 1주 결정**

- 시드 옵션 B: 통신 BE 검증 완료 + 1개 추가 카테고리 검증 + 매출 €15K+/월
  신호가 있어야 협상력 있음. 그 전 시드는 압박 + 윤리 자유 손실 리스크.
- Vlaio/LU 그랜트: TVA 발급 직후 1주 안에 적격성 확인. 적격이면 즉시 신청,
  아니면 옵션 A 회귀. 신청서 작성 = 1~2주 시간 흡수가 트레이드오프.

### 결정 7 — Slim Insights (B2B) **페이즈 7+ → M24+ 평가 시점**

활성 사용자 ≥ 10,000명 + 데이터 N ≥ 1,000명 집계 신호가 의미 있음. 그 전
B2B 영업은 솔로 시간 가장 비싼 활동.

### 결정 8 — `docs/MONETIZATION-ACTUALS.md` 신설 (verifier 자동 갱신)

분기마다 (M3 / M6 / M9 / M12 / M16 / M20 / M24) 실제 비용/매출 vs 가정 기록.
±50% 차이 시 ADR-0004 Amendment 트리거.

## Alternatives considered

### 대안 A — 풀타임 가정의 비용 모델 유지

- **거부 사유**: 운영자 실제 €300/월 vs 가정 €55K/월 = 1/150 격차. 단순
  보정이 아니라 모델 자체 재구축 필요. 풀타임 가정 유지 시 모든 마일스톤
  게이트(M3 €15K cost, M6 €45K)가 즉시 거짓.

### 대안 B — 즉시 시드 모금 (M0~M3에 € 500K 라운드)

- **거부 사유**: (a) 검증 안 된 단일 카테고리 + 베타 0명 + 매출 €0에서 시드
  협상력 없음 → valuation 낮음 → 운영자 지분 희석 큼. (b) 베네룩스 시드
  펀드는 통상 €1M+ 매출 또는 강력한 traction 요구. (c) 헌법 P3 윤리 자유가
  2년 내 시리즈 A 압박으로 손상.

### 대안 C — 페이드 마케팅 조기 도입 (M3부터 €5K/월 Google Ads)

- **거부 사유**: (a) 월 €300 cap 위반. (b) 베네룩스 통신/에너지 비교 키워드
  CPC가 €3~€8 → €5K로 600~1,600 클릭 → 전환율 5% 가정 시 30~80건. CPA €25~€70
  대비 ROAS < 1. (c) Organic SEO + 매체 파트너십(옵션 C)이 솔로에 더 적합.

### 대안 D — 외부 변호사 €800/주 유지

- **거부 사유**: 운영자 €300/월 cap의 10배 초과. 헌법 P5 (legal 에이전트
  의존) 와 직접 충돌. 외부 1회 GDPR 감사(€800)는 매출 발생 후 시행으로 이연.

### 대안 E — 매출 가정 70% 다운 (보수보다 더 보수)

- **거부 사유**: 50% 다운으로도 M10에 net positive 진입 가능 → 운영자 동기
  유지 가능. 70% 다운 시 M16까지 매출 €1,500/월 미만 → 운영자가 프로젝트
  포기 트리거. 보수 정도가 *너무* 강하면 자기실현적 실패.

### 대안 F — Plus 구독을 페이즈 6에 유지 (원 가정 그대로)

- **거부 사유**: 활성 사용자 베이스가 10K 미만일 때 구독 도입 = 5% × 10K =
  500명 × €4.99 = €2,500/월 이론값에서 실제 1/3~1/5 (300~500명 베이스에서
  3% 전환). 시간 매몰 대비 매출 작음. M18 활성 5K + Plus 베타가 더 합리적.

## Consequences

### ✅ 얻는 것

- MONETIZATION.md가 운영자 실제 €300/월 예산과 정합
- M8 베타 단계에서 **net positive 진입 가능** (원 가정 M6 손익분기보다 빠름,
  단 절대 매출 1/15~1/20 작음)
- 무료 티어 한계 도달 시점 명시 → 격상 시점이 매출 신호와 동기화
- 외부 변호사 비용 가정 제거 → 헌법 P5 (legal 에이전트) 정합
- Vlaio/LU 그랜트 시나리오 → TVA 발급 후 운영자 행동 1주 만에 결정 가능
- 시드/풀타임 평가가 M24 데이터 기반 결정 → 압박 없는 진로 선택

### ⚠️ 잃는 것 / 부채

- **절대 매출이 작음**: M12 €1,800/월 vs 원 €180K/월. 시드 협상력 약함.
- **단일 운영자 의존**: 운영자가 사이드를 멈추면 매출 0. 풀타임 4명 분산 위험
  대비 위험 집중 큼.
- **organic only 마케팅**: 베네룩스 시장에서 신생 사이트의 SEO ramp-up은
  6-12개월 → 매출 ramp-up 자체가 느림.
- **그랜트 신청 시간 흡수**: 1-2주. 신청서 + 보고 의무. 적격이지만 거절될
  경우 시간 손실 risk.
- **B2B 매출 (Stream D) M24+ 이연**: 누적 데이터 가치가 크지만 영업 활동이
  솔로에서 비현실 → 시드 후 또는 매체 파트너십(옵션 C) 의존.
- **Slim Plus M18+ 이연**: 구독 매출의 안정성(MRR) 확보 시점 늦어짐.

## 검증 방법

### 검증 1 — 분기별 실제 비용 vs 가정 비교

`docs/MONETIZATION-ACTUALS.md`에 verifier가 자동 기록:
- M3: 인프라 실제 비용 €? vs cap €300
- M6: + Claude API 사용량 패턴
- M9: + 첫 무료 티어 한계 도달 여부
- M12: + 매출 vs 가정 €1,800

차이 ±20% 이내: 가정 유지. ±50% 이상: ADR-0004 Amendment.

### 검증 2 — 분기별 실제 매출 vs 가정 비교

같은 ACTUALS 문서에:
- M8: 첫 어트리뷰션 1건 발생 여부 (이진 신호)
- M10: 월 매출 €1,125 vs 실제 (±20% 합리적)
- M16: 페이즈 5 진입 게이트 4조건 측정 (ADR-0003 §검증 2와 동기)
- M24: 시드/풀타임 평가 입력 (€15K/월 vs 실제)

미달 패턴이 2 분기 이상 지속 시 → 매출 가정 재조정 + scope cut 옵션 (PLAN
A~E) 검토.

### 검증 3 — 그랜트 적격성 (TVA 발급 후 1주)

- TVA 번호 수령 시점 (사용자 보고)
- 그 후 1주 안에 Vlaio/LU/innoviris 적격성 확인 → 적격이면 신청서 착수,
  아니면 옵션 A 회귀
- 그랜트 결정 시점 (적격 가정 시 통상 신청 후 6-12주) → 시나리오 1/2/3 확정

## 영향

- **PLAN.md**: 페이즈 4 어트리뷰션 시점, 페이즈 5 카테고리 확장 시점이 본
  ADR의 매출 가정과 동기. 무료 티어 한계 도달 시점이 페이즈 1.5 / 3.5 / 4.5
  운영 부채 트랙에 부담 추가 가능.
- **ADR-0003**: 짝 ADR. PLAN 일정 결정과 본 비용/매출 가정이 일관.
- **`docs/FOUNDER.md`**: 본 ADR이 §2 함의 4개 (외부 변호사 / GDPR 감사 /
  무료 티어 / Vlaio)의 후속. 단, FOUNDER.md 자체는 변경 안 함.
- **`docs/MONETIZATION-ACTUALS.md`**: 신설 (verifier가 분기마다 갱신).
- **헌법 (CLAUDE.md)**: 변경 없음. P3 (투명성) + P5 (결정은 ADR로) 정신 그대로.
