### 11개월 점프 정당화

ADR-0034 §결정 4 "완성 우선" + §결정 5 "organic SEO 런치" + [ADR-0046](0046-phase-4-closure.md) D3 "페이즈 4 = 사실상 프로젝트 마지막 활성 페이즈" 잠금:

- 페이즈 4 종료 = 베타 트래픽 첫 유입 시점 = **사용자 표면 + 운영자 봉합 인프라가 베타 동반 필수**
- 페이즈 6 본래 일정 (M22~M24) = "런치 후 6개월 안정화" 가정, ADR-0046이 이를 무효화 = "페이즈 4 종료 직후 = 사실상 런치 시점"
- 따라서 페이즈 6 항목 중 **베타 진입 보조 부분 집합**을 M11에 부분 진입 = ADR-0034 §결정 4·5 + ADR-0046 §D3 정합

## 결정 (Decision — 잠정, 운영자 선택 대기)

### D1. 페이즈 6 부분 진입 잠금 (옵션 A 채택 가정)

페이즈 6 항목 중 **베타 진입 보조 등급 A/B 5건만** M11에 부분 진입:
1. **6.9** `/legal/affiliate-disclosure`
2. **6.8** `docs/legal/gdpr-register.md`
3. **6.6** Status 페이지 (`/status` 라우트 + fetcher health read)
4. **6.7** `pnpm harness:bias` Inngest cron (월요일 06:00 UTC)
5. **6.2** Sentry 알림 룰 (Claude 트랙 = runbook 갱신, 운영자 트랙 = cloud 룰 5종 ON = ADR-0046 §D1 동형 분리)

**합계 78 → 83 (+5).** 페이즈 6: 0/10 → 5/10.

### D2. 등급 C 보류 명시

6.1 / 6.3 / 6.4 / 6.5 / 6.10 + 5.5 / 5.6 = **본 ADR 범위 밖**. 각 항목 진입 시 별도 ADR 트리거:
- 6.1 = 베타 데이터 쌓인 뒤 (M12~M13 추정)
- 6.3 = 1.5.2 정식화 후속 라운드
- 6.4 = 회원가입 시스템 (4.6 organic SEO 트랙) 진입 후
- 6.5 = 4.12 흡수 검증 후 + 별 ADR
- 6.10 = 수익 €5,000/월 시점 (ADR-0004 §결정 3)
- 5.5 / 5.6 = 페이즈 5 통신 BE 깊이 측정 (≥ 80% 비교 가능률) 후

### D3. ADR-0046 §D2 잠금 보존

4.5.3 시간 트랙 [~] 유지 = ADR-0046 §D2 잠금 그대로. 본 ADR은 페이즈 6 부분 진입만 다룸, 페이즈 4.5 잔여는 무관.

### D4. ADR-0045 §D2 격상 규칙 페이즈 6 확장 적용

5건 중 6.2 = "Claude 트랙 머지 완료 + 운영자 cloud 트랙 별 진행" = ADR-0045 §D2 + ADR-0046 §D1 동형. 부모 [x] 격상 시 자식 본문에 "**운영자 cloud 트랙 별 진행**" 명시 + cloud 트랙 자식은 [~] 유지.

나머지 4건 (6.6/6.7/6.8/6.9) = Claude 트랙 단독 완결 = 일반 [x] 격상.

## 대안 검토

### 옵션 A (권고): 5건 격상 (78 → 83)

채택 사유: 베타 진입 첫 표면 신뢰 + 운영자 봉합 인프라 봉합 + 6단 게이트 5회 부담 현실적 (4~5시간) + ADR-0045 §D2 + ADR-0046 §D1 정합.

⚠️ 잃는 것: "오늘 93" 운영자 목표 미달 (-10). 6.1/6.3/6.4/6.5/5.5/5.6 진입 별 라운드 부담.

### 옵션 B: 8건 강행 (78 → 86)

옵션 A + 6.3 + 5.5 + 5.6.

거부 사유 (잠정): (1) 5.5/5.6 = 페이즈 2 carousel 추출 = builder 코드 머지 선행 필수 = "문서 단독 격상" 패턴 ❌. (2) 게이트 8회 + PR 8건 = 솔로 사이드 1일 한계 (4~5h) 초과 위험. (3) 5.5/5.6은 페이즈 5 통신 BE 비교 가능률 ≥ 80% 측정 후 격상이 정합 — 측정 0건 상태 격상 = P1 "정보 우선" 약화.

운영자가 옵션 B 강행 시 본 ADR D1에 5.5/5.6 추가 + D2에서 제거 + §결정 잠금 사유에 "운영자 직접 결정"으로 명시.

### 옵션 C: 11건 전부 (78 → 89, 여전히 93 미달)

**거부 권고**. 사유:
- 6.1 = 4.5.1 v0 데이터 쌓이지 않은 상태 격상 = 데이터 거짓 (헌법 §3 P1 위반)
- 6.4 = 회원가입 시스템 0 상태 = `/account/export` 라우트 자체 무효
- 6.5 = 4.12 흡수 검증 안 된 상태 격상 = ADR-0043 §D5 cross-ref 깨짐
- 6.10 = 수익 €5,000/월 미도달 = 외부 €800 지출 정합성 0
- 5.5/5.6 = 페이즈 5 측정 0건

5개 항목 모두 "코드 머지/측정/외부 트리거 미완 상태에서 [x] 격상" = **헌법 §3 P3 위반** + ADR-0046 §D2 "P3 정합" 1일 자가-모순.

### 옵션 D: 격상 0건, ADR-0047만 잠금 (78 유지)

채택 사유 (운영자 휴식 우선 시): 페이즈 4 종료 직후 1일 휴식 + 큐만 잠금. 격상 PR 0 = 게이트 부담 0.

⚠️ 잃는 것: 베타 진입 시점 표면 신뢰 인프라 미봉합. 베타 트래픽 유입 후 사용자 첫 방문 시 `/legal/affiliate-disclosure` 부재 = P3 신호 0.
